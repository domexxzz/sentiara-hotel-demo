# Sentiara — เดโมระบบจัดการโรงแรม

เดโมกดใช้ได้จริง (clickable prototype) ของระบบจัดการโรงแรมและคอนโดปล่อยเช่ารายวัน
ครอบคลุม 5 มุมมอง: **แขก · เคาน์เตอร์ · พนักงาน · เจ้าของ · POS ร้านอาหาร**

> **นี่คือเดโม ไม่ใช่ระบบที่ใช้งานจริงได้ทันที** — ข้อมูลทั้งหมดอยู่ในหน่วยความจำของเบราว์เซอร์
> ยังไม่มีฐานข้อมูลและไม่มีหลังบ้าน รีเฟรชแล้วข้อมูลกลับไปตั้งต้น
> จุดประสงค์คือให้ลูกค้าเห็นและกดเองได้ว่าระบบจะทำงานยังไง ก่อนตัดสินใจสร้างของจริง

## สิ่งที่กดได้จริงในเดโม

การจองหนึ่งรายการเดินทะลุทุกจอ — จองฝั่งแขก → ขึ้นปฏิทิน → เช็กอินที่เคาน์เตอร์ →
สั่งอาหารเข้าบิลห้อง → เช็กเอาต์ → ห้องเด้งไปคิวแม่บ้าน → ตัวเลขขยับในจอเจ้าของ

| ส่วน | ทำอะไรได้ |
|---|---|
| ปฏิทินห้อง 14 วัน | กันจองซ้ำด้วยการเช็กช่วงวันทับกันจริง จองชนวันไม่ได้ |
| จัดห้องติดกัน | จองหลายห้องแล้วพยายามหาห้องเรียงติดกันบนชั้นเดียว และ**บอกตามจริง**เมื่อหาไม่ได้ |
| เรตวันหยุด | ศุกร์–เสาร์ +20% คิดเป็นรายคืน ใช้สูตรเดียวกันทุกจอ |
| กล่องข้อความรวม | รวมแชททุกช่องทางไว้ที่เดียว + ด่านกรอง 4 ชั้นก่อนตอบอัตโนมัติ |
| ใบกำกับภาษี | ตามมาตรา 86/4 ประมวลรัษฎากร · VAT แยกจากยอดรวม |
| ทะเบียนผู้พัก | แบบ ร.ร.3 / ร.ร.4 ตามมาตรา 35 พ.ร.บ.โรงแรม 2547 |
| สิทธิ์ผู้ใช้ | 6 บทบาท ล็อกอินด้วยบัตร NFC · จอเจ้าของเปิดได้เฉพาะเจ้าของกับผู้จัดการ |
| สลับโหมดธุรกิจ | โรงแรม ↔ คอนโดให้เช่ารายวัน ใช้หลังบ้านตัวเดียวกัน ต่างแค่ชั้นแสดงผล |

## สิ่งที่ยังไม่ได้ทำ — พูดตรง ๆ

- **ไม่มีฐานข้อมูลและหลังบ้าน** — ช่องว่างที่ใหญ่ที่สุด ทุกอย่างอยู่ใน state ของ React
- **ยังไม่ได้เชื่อม OTA จริง** (Agoda / Booking.com) — จอ Channel Manager แสดงโครงข้อมูลและ payload ที่จะส่ง แต่ยังไม่ได้ยิงออกไปที่ไหน
- **ยังไม่ได้ต่อระบบกรมการปกครองและ ตม.** — แบบฟอร์มถูกต้องแต่ปุ่มส่งบันทึกสถานะในเครื่องเท่านั้น
- **ไม่มีระบบชำระเงินจริง**

## โครงสร้างโค้ด

```
src/
  hotel/hotelStore.tsx   สโตร์กลาง — ห้อง การจอง บิล แม่บ้าน ข้อความ สิทธิ์ ใช้ร่วมกันทั้ง 5 จอ
  lib/                   ตรรกะที่ไม่ผูกกับ UI
    rates.ts             เรตวันหยุด — แหล่งความจริงเดียวของราคา
    allocate.ts          เลือกห้องติดกัน
    replyGuard.ts        ด่าน 4 ชั้นก่อนตอบข้อความอัตโนมัติ
    tax.ts               VAT และแปลงจำนวนเงินเป็นตัวหนังสือไทย
    roles.ts             บทบาทและสิทธิ์
    property.ts          โหมดโรงแรม / คอนโด
  screens/  desk/  staff/  owner/  pos/    จอของแต่ละมุมมอง
public/rooms/  public/condo/               รูปห้อง
```
